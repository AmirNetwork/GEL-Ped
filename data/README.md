# Data provenance

## Jülich bidirectional corridor experiment

- Dataset: *Bidirectional pedestrian flow in a corridor*
- DOI: https://doi.org/10.34735/ped.2013.5
- Repository mirror: https://doi.org/10.26165/JUELICH-DATA/6M5RN4
- Licence stated by archive: CC BY 4.0
- Sampling rate: 25 frames/s
- Downloaded archive: `2013bidirectional_trajectories_txt.zip`
- SHA-256: `BDEC17C9549B1790FCC02C98A31A62D1ADBD96FA756ED540F07CE636CE97DF7E`
- Download date: 2026-07-22

The archive is intentionally excluded from version control. The loader interprets columns
as pedestrian ID, frame, x (cm), y (cm), and height (cm), following the PeTrack trajectory
format used by the archive. Positions and heights are converted to SI units.
