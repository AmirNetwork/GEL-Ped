GEL-Ped Overleaf package
Author: Amir Ghorbani

Main manuscript: main.tex
Bibliography: references.bib
Figures: figures/*.pdf

Overleaf steps:
1. Upload the complete contents of this package as one project.
2. Set main.tex as the Main document.
3. Use pdfLaTeX as the compiler.

The package compiles with the Elsevier elsarticle class available in Overleaf.
The included main.pdf is the locally verified 13-page output.

The response-to-referee file is included for editorial use but is not imported
by main.tex. Raw third-party pedestrian trajectories are not redistributed.
