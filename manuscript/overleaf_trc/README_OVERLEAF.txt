GEL-Ped Overleaf package
Author: Amir Ghorbani

Main document: main.tex
Bibliography: references.bib
Figures: the PDF files referenced directly by main.tex

Overleaf steps:
1. Upload main.tex, references.bib, and every referenced PDF figure into the
   project root while preserving their filenames.
2. Set main.tex as the Main document.
3. Select pdfLaTeX as the compiler.
4. Compile twice after BibTeX so citations and hyperlinks resolve.

The manuscript uses the Elsevier elsarticle class available in Overleaf. The
included main.pdf is a convenience preview; the release checklist requires a
fresh compile and full-page visual inspection before submission. LaTeX
auxiliary files, raw trajectories, source photographs not referenced by
main.tex, caches, and response letters are not required in the Overleaf source
archive. Keep the final response-to-referee as a separate editorial file.
