# Overleaf project

Upload the complete ZIP to Overleaf and select `main.tex` as the main document. The project uses Elsevier's `elsarticle` class and the `elsarticle-harv` BibTeX style, both available in Overleaf's standard TeX Live installation.

Compile sequence: pdfLaTeX, BibTeX, pdfLaTeX, pdfLaTeX. Overleaf runs this automatically.

Submission files:

- `main.tex`: complete manuscript source with integrated Appendices A-C.
- `references.bib`: verified author-year bibliography.
- `figures/`: seven manuscript figures plus a graphical abstract.
- `highlights.txt`: five journal highlights.
- `source_manuscript.md`: final plain-text source used to generate the LaTeX.

Before submission, the author should confirm the title-page affiliation and email, insert any funding statement or repository DOI, and make the journal-required declaration concerning any generative-AI assistance used during preparation.
